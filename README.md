# Rural Student Learning Assistant (RSLA)

## About the Project

Rural Student Learning Assistant (RSLA) is a web-based learning platform designed to support students in rural areas by providing easy access to educational resources, lessons, quizzes, progress tracking, and learning recommendations.

## Problem Statement

Students in rural areas may face difficulties accessing quality educational resources and personalized learning support. RSLA aims to provide a simple and accessible digital learning platform that helps students continue their learning journey.

## Objectives

- Provide students with organized learning materials.
- Allow students to access lessons based on their subjects.
- Provide quizzes for practice and assessment.
- Track student learning progress.
- Provide learning recommendations.
- Create a simple and user-friendly interface.

## Features

- Student Dashboard
- Subject and Topic Selection
- Lessons
- Quizzes
- Progress Tracking
- Learning Recommendations
- Simple and Responsive User Interface

## Technologies Used

- HTML
- CSS
- JavaScript
